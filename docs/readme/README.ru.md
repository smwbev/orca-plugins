## Как добавить маркетплейс в Orca

1. **Настройки** → **Plugins** → включите систему плагинов.
2. Откройте **Marketplace sources**.
3. Вставьте адрес в поле **Git URL**, оставьте ref `main` и нажмите **Add source**:

   ```
   https://github.com/smwbev/orca-plugins.git
   ```

4. Источник появится в списке **Configured sources** под именем **Orca s3dev Plugins** и будет закреплён за тем коммитом, который Orca скачала.
5. Откройте вкладку **All**, найдите нужный плагин и нажмите **Install**.

Orca использует системные учётные данные Git, поэтому приватные репозитории подключаются так же.

> **Это не то же самое, что «Install plugin».** Адрес маркетплейса вставляется в **Manage sources**, а не в окно **Install plugin**: индекс маркетплейса — не плагин и не может быть установлен как плагин. При попытке Orca ответит *«Add an explicit #ref …»*, потому что то окно ждёт репозиторий плагина, привязанный к тегу, например `https://github.com/smwbev/orca-russian.git#v5.1.75`.

> Названия разделов приведены по-английски намеренно: раздел плагинов Orca запрещает переводить, поэтому он остаётся английским даже после установки русского языкового пакета.

### Обновление и удаление

- Значок обновления рядом с источником заново скачивает индекс и закрепляет его за свежим коммитом.
- Значок корзины удаляет источник. Уже установленные из него плагины остаются — их нужно удалять отдельно.

Каждая запись закреплена за конкретным тегом релиза, а не за подвижной веткой: установка всегда приводит к проверенному содержимому. Когда у плагина выходит новая версия, поле `ref` в [`orca-marketplace.json`](../../orca-marketplace.json) обновляется, и после следующего обновления источника Orca предложит обновиться.

## Формат индекса

```jsonc
{
  "name": "Orca s3dev Plugins",   // отображается в списке источников Orca
  "owner": "smwbev",              // должен совпадать с аккаунтом, где лежит индекс
  "plugins": [
    {
      "id": "smwbev.russian",     // publisher.id — должен совпадать с манифестом плагина
      "source": {
        "kind": "git",
        "url": "https://github.com/smwbev/orca-russian.git",
        "ref": "v5.1.90"           // тег, ветка или коммит
      },
      "description": "…",
      "categories": ["languages"]
    }
  ]
}
```

Два правила, о которых стоит знать до добавления записи:

- **`id` обязан совпадать с манифестом самого плагина.** Orca сверяет идентификатор из индекса с парой `publisher` + `id` в `orca-plugin.json` и при расхождении отказывает в установке.
- **Зарезервированные идентификаторы.** Издатель `stablyai`, а также любой идентификатор, начинающийся с `orca-`, зарезервированы за официальным маркетплейсом. Если такая запись не ведёт в организацию stablyai, Orca отклоняет **весь индекс целиком**, а не одну запись — перестают устанавливаться все плагины из этого источника.

Учтите также, что Orca сейчас скрывает записи с категориями `themes`, `icons`, `icon-themes`, `terminal-themes` и `skills` — установка для них ведёт в тупик. Категория `languages` и остальные отображаются нормально.
